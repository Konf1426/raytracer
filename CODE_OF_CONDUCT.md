# Code of conduct

Participation in this project's issues, pull requests and reviews should be
respectful and welcoming.

- Discuss the code and the evidence. Give constructive, specific feedback.
- Respect different backgrounds and experience levels.
- Do not harass, threaten, insult or discriminate against participants.
- Do not publish another person's private information.

If a discussion becomes uncomfortable, stop and ask for help from the repository
owner. No dedicated private reporting address is configured yet: use an existing
private contact channel with the owner for sensitive reports. Do not post private
details in a public issue. The owner must define a private reporting channel
before inviting a broader community.
