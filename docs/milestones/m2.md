[Official request](https://learn.glassworks.tech/raytracer/milestone-m2/): add a
triangle and JPEG output to m1, with tests first and minimal changes to existing
files. Due December 6, 2026 at 23:59, Paris time. The delivered tag is `m2`.

## Implemented

- [x] Cross product, independently calculated tests and an observed red phase.
- [x] Triangle implements Shape without changing Scene, Renderer or other shapes.
- [x] Tests for hit t/point/normal/colour, misses and a triangle behind the ray.
- [x] Nonunit directions, clipped bounds, edges, winding and invalid vertices.

See [m2 validation](../engineering/m2-validation.md) for commands, observed results
and environment limitations. Configuring a CI job does not prove it has passed.

## Historical m1 gaps

The m1 tag is preserved. It writes PPM, whereas the published
[m1 brief](https://learn.glassworks.tech/raytracer/shading-and-shapes/milestone-m1)
asks for PNG. It also stores Colour on shapes and shades in Renderer, whereas the
course introduces Material and asks for its ADR. m2 reuses that existing shape
contract and colour representation; it does not retrospectively claim those m1
requirements were met. There was no recorded PNG-library comparison in m1.
Correcting Material separately would change existing shape, hit and shading
contracts; that is outside this two-feature extension and needs its own rationale.

## Before final delivery

- [ ] Owner reviews the code, redoes the sample calculations and can explain it.
- [ ] Owner accepts or revises proposed ADRs; no AI changes them to Accepted.
- [ ] Run make build, make test, make run and make clean in the dev container.
- [ ] Push the reviewed branch and confirm hosted Debug/Release CI succeeds.
- [ ] Review `git diff --name-status m1 HEAD` and the file-change rationale.
- [ ] Create and push m2 on the reviewed commit, without moving m0 or m1.

After review, from the container:

```sh
make build
make test
make run
./build/unix-debug/tests/jpeg_check render.jpg 640 360
git diff --name-status m1 HEAD
git tag --list
git tag m2
git push origin HEAD
git push origin m2
```

Do not force-update an existing milestone tag. Preserve the m0 discovery report
and both original milestone previews.
