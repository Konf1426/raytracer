# 3. Test with Catch2

## Context

The brief asks for Catch2 and TDD. Tests should read like mathematical examples.
GoogleTest is an alternative; raw assertions lack comparable test reporting.

## Decision

Propose Catch2 v3.8.1, matching the course reference, downloaded by CMake
FetchContent. Link `Catch2::Catch2WithMain`. Use absolute tolerances for
floating-point comparisons rather than exact equality.

## Status

Proposed

## Consequences

Tests use short named cases and get individual CTest results. Initial builds need
GitHub access and compile Catch2 from source. Changing frameworks requires
rewriting assertions; dependency upgrades require an explicit version change.
