# 9. Export a PPM image independently of rendering

## Context

m1 needs a viewable image. PNG would require an encoder dependency. PPM is a simple
format that can be checked by hand and written with the standard library.

## Decision

Propose an Image that stores linear RGB colours and a separate P3 PPM writer.
Clamp output channels to [0, 1], apply a gamma-2 square root, then round to [0, 255].
Store rows top to bottom. Report stream and file errors. The CLI accepts an output
path and optional positive width and height, each at most 4096.

## Status

Proposed

## Consequences

Image storage, shading and encoding have distinct responsibilities. PPM needs no
runtime dependency but produces large files and some viewers cannot open it.
Gamma 2 is a simple display approximation, not the exact sRGB transfer function.
The dimension limit bounds the CLI allocation; large images still consume memory
because each pixel holds three doubles. The library does not impose the CLI limit.
The checked-in PNG preview is a lossless conversion of the program's PPM output,
not a separate renderer.
